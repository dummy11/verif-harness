# verif-harness 3.0.0

发布于 2026-11-02：[下载本版本](https://github.com/dummy11/verif-harness/releases/tag/v3.0.0)。
verif-harness 提交为 `b22346312c1a48a0ca22d59f7f025de428f3ed5a`；
配套 [NSIM v0.1.0](https://github.com/dummy11/NSIM/releases/tag/v0.1.0) 提交为
`5ae785d0efbcd8e14a194e40945a336c05642918`。

本版本将程序安装与项目初始化分开，固定配套 nsim 0.1.0。
准确的 NSIM commit、安装包摘要和工具依赖清单见发布附件 `release.json`。

- `install`：用户或系统级安装，多个版本共存，相同安装包复用。
- `bootstrap`：逐项确认工程输入，新增必填只读 RTL filelist，初始化项目控制状态和 nsim 配置。
- `restart`：在项目或子目录检查选定版本、Skill/MCP、Dashboard，再进入项目配置的 Agent。
- `switch`：一起切换 verif-harness 与配套 nsim，检查数据库兼容性和在途任务，保存数据库备份与恢复记录。
- 发布物包括 wheel、sdist、独立安装器、发布清单和 SHA256SUMS；支持已有 Python 的控制面离线包。

已有项目需使用完整 `bootstrap --refresh` 参数登记发布版本。重新进入项目使用 `restart`，
不再逐项目安装程序。切换后执行 `restart` 更新 Agent 入口并准备相应版本的 Dashboard。
初始化、重启和工具切换不会代替文档审批或验证结果验收。

本版本只切换数据库 schema 兼容的版本，不自动迁移或降级数据库。沿用 NSIM 的目录命名和
TOML catalog 规则；同一账号的验证目录名称须唯一。Codex/Kimi 仍需用户安装并认证。

发布检查覆盖控制面测试、Verilator 示例、分发内容校验，以及临时目录中的安装复用、
双项目版本隔离、切换与恢复、Dashboard 访问、离线安装和内容变更拒绝。
NSIM 的 Linux/macOS 测试结果见配套版本 CI。以上不代表商业仿真器、真实 LSF/NFS
或目标服务器系统权限部署已完成验收。
